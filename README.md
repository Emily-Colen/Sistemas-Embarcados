# Sistemas-Embarcados
Entregaveis projeto em Sistemas Embarcados 

FEAU - Faculdade de Engenharias, Arquitetura e Urbanismo 
Turma: 8UNA Engenharia da Computação 

Alunos: Ana Livia Fernandes, Bryan Goulart e Emily Colen.


Atualmente, o projeto já apresenta funcionamento dos motores, do controle remoto e dos sensores ultrassônicos, com resposta adequada aos comandos e às leituras de distância.
Como próximos passos, ainda é necessário realizar o ajuste e calibração dos sensores infravermelhos TCRT5000, finalizar a estrutura de fixação do sensor ultrassônico traseiro e, por fim, realizar os testes completos na arena, validando o comportamento do robô em condições reais de competição.
